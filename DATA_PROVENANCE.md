# Data Provenance

No project dataset is admitted by default.

Each project adds a local provenance record containing:

- immutable source identity or synthetic generator version
- owner and license
- collection or generation date
- row grain and schema
- transformations
- privacy classification
- redistribution decision
- retention and replacement policy

User-uploaded demo data remains runtime-only and is never committed, logged,
snapshotted, or added to portfolio fixtures.
